# DevLinks

## Descrição

O DevLinks é uma página de links pessoais desenvolvida como projeto prático do curso Discover, da Rocketseat.

O projeto permite reunir links e redes sociais em uma única página e possui suporte aos modos claro e escuro.

O objetivo do projeto foi colocar em prática os fundamentos de desenvolvimento web estudados durante o curso.

## Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Figma
- Visual Studio Code

## O que aprendi

Durante o desenvolvimento deste projeto, pratiquei conceitos fundamentais de desenvolvimento web, como:

- Estruturação de páginas com HTML
- Estilização utilizando CSS
- Box Model
- Flexbox
- Variáveis CSS
- Pseudo-seletor `:hover`
- Responsividade com Media Queries
- Dark Mode e Light Mode
- Animações com `@keyframes`
- Manipulação do HTML utilizando JavaScript
- Manipulação de classes com `classList`
- Manipulação de atributos com `setAttribute()`
- Funções e condicionais em JavaScript
- Uso do DevTools do navegador
- Controle de versão utilizando Git
- Criação e publicação de repositórios no GitHub
- Utilização do Figma como referência para desenvolvimento da interface
